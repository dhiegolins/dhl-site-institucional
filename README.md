# DHL — Site institucional

Repositório dedicado ao site institucional da DHL Empreendimentos Digitais Ltda.

**Status:** preparação; GitHub Pages não habilitado.

A publicação pública dos documentos jurídicos e sua vigência no Supabase dependem de anexar e conferir os três PDFs consolidados (Termos de Uso, Política de Privacidade e Acordo de Tratamento de Dados), revisar as URLs HTTPS, obter aprovação jurídica aplicável e registrar os hashes SHA-256 das versões publicadas.

Não usar este repositório para código ou segredos do CRM SaaS.
